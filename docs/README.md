## Documentation Standards

All documentation in this folder follows these principles:

- **Code as source of truth** - Documentation reflects actual implementation
- **Practical examples** - Every guide includes working examples
- **Troubleshooting** - Common issues and solutions included
- **Progressive disclosure** - Quick start → detailed guides → reference

## Contributing to Documentation

When updating documentation:

1. **Verify against code** - Ensure docs match actual implementation
2. **Test examples** - All code examples should be tested
3. **Update this index** - If adding new docs, update this file
4. **Keep it simple** - Write for clarity, not complexity
